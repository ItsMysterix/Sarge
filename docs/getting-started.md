# Getting Started with Sarge

Welcome to Sarge, the ultimate deployment and management platform for your applications.

## Key Features
- **Instant Deployments**: Connect your GitHub repo and we handles the rest.
- **AI-Powered Analysis**: Our AI automatically detects your framework, ports, and configuration.
- **Monitoring & Logs**: Real-time visibility into your running services.
- **Notification Center**: Stay updated on deployment status and system alerts.

## Create Your First Project
1. Go to the [Projects](/projects) page.
2. Click **Create Project**.
3. Enter your project name and click create.
4. Your project dashboard will guide you through connecting a repository.

## Support
If you run into any issues, use the **Feedback** button in the header to report a bug or suggest a feature.
